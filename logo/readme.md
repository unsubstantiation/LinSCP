# LinSCP logo

The mark is a fairy penguin - *Eudyptula minor*, the smallest penguin, whose
feathers are slate blue - with a blue arrow arriving from the left (downloads)
and a green arrow leaving to the right (uploads).

## Files

| File | What it is |
| --- | --- |
| `linscp-mark-source.png` | 1600x1600 master artwork on flat white. Keep it as the pristine source. |
| `linscp-mark.png` | Master mark, background removed, full width. Used by `../readme.md`. |
| `linscp-mark-compact.png` | Penguin with simplified solid arrows, for 32-64px sizes. |
| `linscp-mark-symbol.png` | Penguin only, for 16-24px sizes. |
| `linscp-badge.png`, `linscp-symbol.png` | Rounded-tile compositions at 1024px. |
| `linscp-logo.png` | Horizontal lock-up: badge plus wordmark. |
