Workspaces ✕
A workspace reopens the current tabs, their two pane directories and the active tab. Passwords are not stored in it.
Bookmarks ✕
A bookmark stores a directory of one panel. It stores no session, password or host key.
Session URL ✕
The URL opens this site in this client. The password is left out unless you ask for it.
A URL with a password is a secret. It is shown and copied here, never written to the command log.
Import sessions ✕
Sites are read from an OpenSSH client configuration or a FileZilla sitemanager.xml file. Passwords are encrypted with sessions.key when they are stored.
Preferences ✕
These are the defaults a transfer and a confirmation start from. A transfer dialog still lets you change them for one run.
Cleanup stored data ✕
Each item is one file or directory this client writes. Removing it cannot be undone, and the parts you leave unticked are not touched.
🖥️ Remote desktop ✕
Open a desktop session on the remote host. RDP (3389, xrdp), VNC (5900, TigerVNC), SPICE (spice-vdagent) ride the SSH tunnel when a jump is configured; X2Go/NX and X11 are transported over SSH direct-tcpip. Wayland sessions use waypipe, X11 uses ssh -X.
Installer script (auto-detects Debian/Ubuntu, Fedora/RHEL, Arch, openSUSE via /etc/os-release) 

          
Runs on the server via the SSH session (sudo when not root, DEBIAN_FRONTEND=noninteractive for apt). Shows apt/dnf/yum/pacman/zypper variant for xrdp/tigervnc-server/spice-vdagent/x2goserver.

        Backup / Restore
        ✕
      

      

        
Full export of sessions, workspaces, bookmarks, preferences, host keys and custom commands as a single JSON bundle (LF, 0600, CRLF-tolerant). The encrypted password key is stored unwrapped so a Debian export restores on Fedora/Arch/Windows/Android and vice-versa. Nothing is written until you choose a file.

        

        

        
Also available as CLI: linscp backup export <file> / linscp backup import <file>

        LinSCP Commander
        ✕
      

      

        
Sessions opens the site manager: stored sessions are shared with the
        console client, and each tab keeps its own connection open.

        
Transfers run in the queue at the bottom. They can be paused,
        cancelled and retried; a cancelled transfer does not disturb the session.
        You can also drop individual files from your desktop onto the remote pane to upload them.

        
Synchronize compares the two panes and shows the plan before it
        changes anything. "Both" uses the record of the previous synchronization to
        tell a change from a conflict.

        
View (F3) opens a selected text file read-only. Edit (F4)
        opens a local or remote text file in the built-in editor. Saving checks that
        the file has not changed since it was opened; remote edits upload to the server.

        
Commander keys: F1 help, F2 rename, F3 view, F4 edit, F5 copy to the
        other panel, F6 move files to the other panel, F7 new directory, F8 delete,
        F9 properties/rights, F10 close session. Ctrl+A selects all; Enter opens a
        directory; Backspace goes up one level. Move is available for files; folders
        can still be copied, but are not moved by the cross-panel move action.

        
The LinSCP command console runs commands in the live session of the current tab.

        
This run's API token: 

        Every request the page makes carries it, and the backend refuses an
        /api/ call without it, so only a page served by this run of the
        server can drive it.
