## Scope and evidence limitations

- Verified means the stated scoped behavior has named automated evidence, not every upstream variant.
- Source/test citations record where evidence is defined, not a claim that every suite ran in this workspace.
- Mock-server/browser fixtures do not certify every real server, browser, file manager or architecture.
- Missing capabilities are retained and must not be deleted to pass the full-parity gate.
- The Wayland and X11 behavior is established from the sources, from fixtures that say which display server this is, and from a check that refuses the X11-only shapes; no case in this ledger runs against a live compositor, so a real Wayland session is not certified by it.
- Suites flagged not runnable under a platform execute no case there; a verified row cites only suites that run on the platforms it names, with only cases its checks list.
